# Fixture-backed fallback walkthrough

The [short walkthrough video](fixture-walkthrough.webm) and six screenshots show the local browser fixture for setup, ownership, grants, approvals, distributions, and a contributor view. The captured pages carry a **fixture walkthrough** label because the displayed chain responses are deterministic fixtures and the browser does not create live wallet signatures. These artifacts demonstrate the interface; they are not evidence of a testnet deployment or completed payments.

Recreate them from the repository root with `pnpm demo:fallback`. This starts the local fixture RPC and Next.js development server, captures the six pages, and saves the video here. The NEAR Sandbox suite (`pnpm test:sandbox`) separately proves the real local-chain governance, claim, funding, failed payout, and retry path. The live testnet evidence is separate; see the [payout rehearsal](../testnet-rehearsal.json) and the [browser rehearsal](../testnet-browser-rehearsal.json).

Screenshots: [setup](setup.png), [ownership](ownership.png), [grants](grants.png), [approvals](approvals.png), [distributions](distributions.png), [personal view](personal.png).

The [live testnet walkthrough](live-testnet.webm) is a separate 31-second read-only recording of the deployed company setup, ownership, grants, approvals, distributions, and activity pages. It was captured from the normal production build after the live governance, payout, and sponsored-claim rehearsals. The [browser receipt evidence](../testnet-browser-rehearsal.json) and [payout evidence](../testnet-rehearsal.json) establish the signed actions and final chain state; the video itself does not show a wallet prompt or a transaction being signed. Recreate the recording with the production server at `http://127.0.0.1:3000` and `node scripts/record-live-demo.mjs` from `apps/web`.
